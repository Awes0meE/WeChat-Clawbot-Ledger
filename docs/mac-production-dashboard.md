## 页面与检查范围

首页显示整体状态、账本／微信记账／公网访问三张卡片，以及供电、立即可用磁盘和 Mac 启动时长；提供打开账本的链接。模型、HTTP/MCP、微信和 Tunnel 的详细检查放入默认关闭的“查看运行详情”。具体授权异常仍会提升到首页，不因折叠而隐去。Mac 启动时长不替代业务连续健康证据；页面不提供登录、启用、重启、写账或修改配置按钮。

独占后台操作暂时阻止状态核验时，显示“后台任务进行中”；只有三项服务都在运行才提示服务仍在运行。真实维护停服单独显示“正在维护”。断连、过期或不匹配的状态不会继续宣称正常。本次四项页面回归通过，实际浏览器在 1280×800 和 390×844 检查通过，无横向溢出，详情展开正常。

监听固定 `127.0.0.1:18990`；验证模式只使用系统分配的临时回环端口。只允许对应端口的 localhost/127.0.0.1 Host、同源请求、GET 和 HEAD。其他 Host/Origin、写方法和私有文件路径拒绝。页面使用固定本地脚本/样式、禁止嵌入和缓存，不加载外部资源。

前端每五秒刷新状态，授权检查每五分钟在后台进行，不等待检查结束才更新服务概览。每项只允许一个在途检查；门禁、宿主进程、维护/故障状态或容器身份/启动时间变化会使缓存失效，旧在途结果不能填入新实例。单项失败清除该项结果；页面失联、过期、未来时间或收到错误运行环境时清除当前健康与授权展示。

状态汇总继续执行 [生产启用与运行身份检查](mac-authorization-recovery.md#生产状态汇总入口)。模型只读凭据检查不证明云端推理；账本检查不写交易或查询历史；微信只读取当前接收器的最近轮询；Tunnel 最近注册不代替实时公网验收。页面明确保留这些范围。

## 不可变准备

在干净的已提交源码中，以已准备的真实生产宿主为目标：

```sh
node scripts/mac/prepare-production-dashboard.mjs '<不可变生产宿主目录>'
```

入口只在 Git 外 `~/Library/Application Support/Clawbot/production-dashboard-releases/` 生成候选。固定清单包含 22 份脚本与页面资源，每份普通文件必须只读且 SHA-256 匹配；清单还绑定精确生产宿主目录与完整运行规格，并核对生成的独立 LaunchAgent 模板。不会复制业务数据或凭据，不安装任务，不启动看板，不改启用门禁。

独立看板任务名为 `com.clawbot.mac-production-dashboard`。它只观察生产服务，业务守护仍由 `com.clawbot.mac-production-host` 负责。

## 首次从测试看板切换

下面的仓库入口只处理旧测试看板 → 生产看板。后续生产看板 → 新生产看板的更新，本次使用仓库外的专用操作脚本核验确切任务、旧包、端口和业务不变，再替换 UI 任务并保留回退记录；该步骤尚未封装成通用仓库命令，不能重复调用首次切换入口代替。

只有完成正式切换、真实生产宿主已经启用并健康后，才能执行：

```sh
node scripts/mac/switch-production-dashboard.mjs '<不可变生产看板目录>'
```

入口先核对生产门禁、宿主进程、三服务身份和启动时间，再检查旧测试宿主的不可变源码、完整任务配置、看板子进程与端口归属。私有 `operations/dashboard-switches/<批次>/` 先落盘保存原任务和切换记录，然后卸载旧看板任务、移除其登录启动文件，安装新任务。旧测试容器不会因此被删除或停止，后续清理由独立流程处理。

新页面必须来自预期进程和候选版本，返回新鲜的生产健康状态；结束时还要确认生产门禁、宿主进程、三个容器及其启动时间均未改变。等待健康时释放操作锁，避免阻挡业务宿主正常采样。任何未知任务或端口占用都拒绝接管。

可捕获的切换失败会卸载已确认属于本次的新任务、恢复原任务并验证旧页面；旧任务尚未退出时可以保留并验证原进程。无法核对归属或生产发生变化时，保留记录并报告需要处理，不宣称恢复成功。此回退只涉及看板任务，不恢复业务数据、不改门禁、不启动微信或 Tunnel。

切换进程被强制结束后，使用当次私有记录明确恢复旧看板：

```sh
node scripts/mac/restore-dashboard-switch.mjs '<operations/dashboard-switches/批次目录>'
```

新切换记录使用 version 2，包含原切换进程号。接续先验证完整 started 记录、只读原任务、候选与源码绑定，确认原进程已经退出，核对两个任务及端口归属，然后恢复旧看板并写入独立恢复记录。已完成的切换、没有进程身份的旧格式、未来时间、损坏或可写记录均拒绝。重复恢复只验证或补齐相同旧任务，不覆盖后续安装的不同版本。

接续不要求生产服务健康，也不会调用生产启停或数据恢复。它仅报告没有执行生产操作，不把这段时间生产状态未知写成生产保持健康。共用操作锁仍占用或残留时保持拒绝，不能自动抢锁；需要先核对锁的原操作及可能仍存活的子进程。强制中断发生在锁释放前、任务文件半写入或旧看板源文件损坏时，保留现场供人工核验，不自动覆盖。
