完整脱敏对应表在 [config/expense-category-icons.json](../../config/expense-category-icons.json)。图标为可缩放字体，没有固定 64×64 或 128×128 像素限制；本次预览使用 64 px，窄屏为 52 px，实际账本沿用自身显示尺寸。

按完整一级／二级名称定位后，仅通过原生 `transaction/categories/modify.json` 更新二级分类 `icon`。同一次请求里的 ID、名称、父分类、颜色、备注和隐藏状态全部沿用最新读取值。每项写入前再次检查原记录，写入后检查服务器返回值，最后比对整个分类树；没有修改一级分类、分类顺序或交易，没有重启或替换任何生产服务。

## 使用与恢复

刷新账本页面后显示新图标。以后可在账本“分类”编辑中选取其他内置图标。Git 中的对应表只记录方案，不会自动覆盖用户后续修改，也不改变旧隔离测试初始化脚本的行为。

修改前／后分类、账户与交易快照、逐项操作日志和验证回执保存在仓库外的私有 operations 目录，权限仅当前用户可读写。需要撤回时，先比对当前分类与本次完成状态，再通过分类修改 API 仅还原目标图标；不要恢复整个数据库或覆盖后来的账目。私有快照及其中的业务 ID 不入 Git。
