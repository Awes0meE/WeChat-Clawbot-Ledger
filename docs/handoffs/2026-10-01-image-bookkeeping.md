## 行为与边界

用户选择明确已付款且最终金额唯一时直接入账，有疑问才确认。实现沿用固定 OpenClaw 2026.8.2、GPT-5.6 Sol 官方 Codex harness 与现有六工具，不增加识图服务。每条当前图片最多一笔支出；一图多订单、未付款及退款不自动记账。以最终实付总额为准，图片没有付款时间时采用原始收到时间，并在回执说明。

微信接收插件在已授权消息 dispatch 的异步上下文中传递当前消息、账户、发送者及媒体路径。记账插件与真实入站记录及受控媒体文件逐项关联，独立校验结构化提取结果；模型参数和提示文字不能授予附件权限。固定版本的钩子没有完整传递自定义上下文或消息首部，实际验证证明不能依赖这两条替代路径。没有修改官方 harness 或上游框架。

歧义图片保存独立编号候选，最多十笔、十分钟有效；回复“确认第N笔”或“取消第N笔”。多笔候选下裸确认不得猜选，普通查询不丢弃图片候选。更正先取消原候选再发送完整消费。确认沿用原始消息时间和永久确认去重；重启不恢复已消费或过期候选。

原始消息去重之外，同一用户的确切附件哈希防止重复入账；已记录的图片优先返回处理状态，不依赖再次视觉提取。不同截图提取出相同订单号时要求确认是否另一笔；订单号不可读或模型未提取时，不能保证不同图片代表的同一订单被识别。图片哈希与字段一致性不能证明视觉判断绝对正确。

回执库只增加 `image_expense_links` 和 `image_expense_proposals`，旧交易、回执、确认去重、迁移记录与运行撤销记录保持。真实图片、订单号、收货信息及实际金额留在 Git 外私有验收目录。
