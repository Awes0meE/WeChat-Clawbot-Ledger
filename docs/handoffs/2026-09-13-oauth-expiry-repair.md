## 实际故障

用户报告“记账失败，修一下 tunnel”。排查时公网首页与健康接口均返回 HTTP 200；15:26 的微信消息已经到达，但在模型执行前报 `openai:default` 不存在。

1. 原 Codex seed 的 access token 于 15:14:06 到期。OpenClaw 2026.8.2 对它只建立 runtime-only 外部授权覆盖，生产 agent 数据库里没有持久 OAuth profile。过期 seed 被忽略后，模型入口找不到选定 profile，尚未走到记账工具。
2. 在独立暂存环境中，将同一账户授权通过官方 writer 保存后，官方模型实际调用成功，并自动续期至十天后。随后单独复现：未启用官方 `openai` 插件时，强制续期返回 provider configured but unavailable。此前生产仅允许三个插件，确有这一第二处缺陷。

因此，仅重启 Tunnel 无法修复这次记账错误；首页与进程健康也不能证明模型可用。
