## 停服与导出的边界

私有操作脚本已通过 Windows PowerShell parser 和只读停服预检：三项任务、九个已识别进程、零在途业务。它复核任务定义、配置哈希、端口 owner 和进程身份；执行模式才禁用任务并停止精确生产进程，保留原始任务定义。未获得现场确认前不执行。

正式导出器缺少真实停服回执时实测拒绝，且不创建 final 目录。执行时反复核验旧任务禁用和端口关闭，原始状态、WAL、独立模型授权、任务定义及链接清单先保存成原始包；所有规范化都发生在副本。账本和回执须与原始字节副本的全表审计一致，之后才生成九卷清单和传输归档。原始包不覆盖、不用在线预览冒充。

Mac 导入、正式授权/微信/公网验收、生产看板切换、正式加密备份与异机恢复、测试实例退役尚未执行。正式异机备份计划保存在 Windows 专用私有目录，密钥另存分开的私有位置；实际复制和恢复结果随切换补充。
