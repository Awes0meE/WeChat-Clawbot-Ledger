# Mac 运行诊断记录

2026-09-21 启用。此前存储检查只留下“故障锁定”，没有保留底层异常；现在将每轮采样、命令失败、生命周期动作和故障前状态保存在 Mac 私有目录。现有存储停机、人工对账和恢复策略保持不变，不能把诊断记录上线称为已经消除2026-09-21 存储采样故障的根因。

## 记录范围

- 宿主每轮检查保存状态样本，目标间隔 15 秒；已有检查未完成时不重入，超过 45 秒的采样间隔额外留事件和快照。
- 保存主机与 Docker 卷可用空间，主机内存、负载、开机时长和记录进程内存；三容器身份、健康、启动/退出时间、重启计数及 OOM 标志。每分钟额外读取一次 Docker CPU、内存和进程数，最多等待 5 秒，失败不改变业务控制决定。
- Docker 命令开始前原子更新 `progress.json`。超时、非零退出和慢命令（至少 2.5 秒）保存所属阶段、耗时、超时预算、退出码、信号和错误类别。能区分存储卷身份检查、主机空间读取、卷空间辅助容器及服务启动/停止。
- 第一次存储故障在停止业务前保存诊断，同时进入既有故障文件；后续失败不覆盖第一次故障时间和证据。状态变化、长采样间隔和未捕获异常也会保存快照。进程异常观察不拦截 Node 的正常失败退出。
- 新宿主启动时保留上一个进程最后的进度，并从轮转日志恢复近期样本；即使进程来不及记录退出，也能知道上次运行到哪一步。没有声称突然断电时最后一次未同步的普通采样一定落盘。

不保存命令参数、环境变量、微信正文、交易内容、令牌或原始 stdout/stderr。错误使用固定类别和受限结构，另保留输出字节数及 SHA-256 供关联；未识别的错误标为 `unclassified`，不会冒充已知根因。记录不是完整请求跟踪，也不替代微信写入或手机送达验收。

## 容量和权限

目录为本机用户的 `~/Library/Application Support/Clawbot/operations/runtime-diagnostics`，目录权限 700、文件权限 600，只允许当前用户的普通文件，拒绝符号链接和硬链接目的地。

| 文件 | 用途 | 上限 |
| --- | --- | --- |
| `samples.jsonl` 及 `.1`—`.7` | 运行采样 | 每份 4 MiB，共 32 MiB |
| `events.jsonl` 及 `.1`—`.3` | 错误、慢命令、状态和生命周期 | 每份 1 MiB，共 4 MiB |
| `incident.json` 及 `.1`—`.7` | 触发原因和之前的采样 | 每份约 256 KiB，共约 2 MiB |
| `progress.json` | 当前或最后一个检查步骤 | 一份固定结构快照 |

合计约 38 MiB，上限小于 40 MiB；自动轮转，不依赖手工清理。每个故障快照最多包含此前 120 条样本，通常约 30 分钟；受 256 KiB 上限约束，过大的快照会裁去最早的样本。常规日志按字节保留，不承诺固定天数。日志不上传云端，不进入 Git。

日志写入错误不阻止现有业务控制流程。错误计数通过宿主状态暴露，看板“查看运行详情 → 运行记录”显示“正在记录”或“记录保存失败，需要检查”；保存失败也会提升到首页提醒。故障状态在当前记录进程内保留，修复记录目录后应通过已核验的宿主切换/重启流程重新确认。旧宿主显示“尚未启用”，过期或断连页面不继续显示正常记录。
